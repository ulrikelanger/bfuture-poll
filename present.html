How polls get in

  • A slide with #poll1 on it is replaced by live poll 1, #poll2 by poll 2, and so on.
  • A slide with #join on it shows the join screen with the QR code.
  • Keys: → / space / clicker = next · ← = back · type a number + Enter = jump to that slide · B = black screen · Esc = back to this page
